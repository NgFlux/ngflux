The NgFluxConfig object allows you to configure global settings, default behaviors, and security baselines across all NgFlux components, services, pipes, and guards.

By defining this configuration at the root of your application, you ensure a uniform user experience and eliminate repetitive component-level properties.

To configure NgFlux globally, pass the NgFluxConfig object into the provideNgFlux provider function during your application's bootstrap phase.

Below is the complete breakdown of properties available within the NgFluxConfig interface.

Property Type Required Default Description
loading LoadingOptions No
dialog DialogOptions No
pagination PaginationOptions No
