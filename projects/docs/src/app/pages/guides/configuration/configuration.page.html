The NgFluxConfig object allows you to configure global settings, default behaviors, and security baselines across all NgFlux components, services, pipes, and guards.

By defining this configuration at the root of your application, you ensure a uniform user experience and eliminate repetitive component-level properties.

To configure NgFlux globally, pass the NgFluxConfig object into the provideNgFlux provider function during your application's bootstrap phase.

Below is the complete breakdown of properties available within the NgFluxConfig interface.

Property Type Required Default Description
loading LoadingOptions No undefined Sets the initial global options for the loading feature.
dialog DialogOptions No undefined Sets the initial global options for dialog boxes.
pagination PaginationOptions No undefined Sets the initial global options for pagination component.

Below is the complete breakdown of properties available within the LoadingOptions interface.

Property Type Required Default Description
showOnRouteNavigation boolean No false Shows loading animation when a user navigates application's routes.
component NgFluxComponent No undefined Component to be used instead of the NgFlux's default loading component.

Global options for the dialog boxes.

Below is the complete breakdown of properties available within the DialogOptions interface.

Property Type Required Default Description
alert DialogAlertOptions No undefined Default options for the NgFlux alert dialog box.
confirm DialogConfirmOptions No undefined Default options for the NgFlux confirmation dialog box.
prompt DialogPromptOptions No undefined Default options for the NgFlux prompt dialog box.

Global options for the pagination component.

Below is the complete breakdown of properties available within the PaginationOptions interface.

Property Type Required Default Description
preload boolean No false When set to true the (callback) output signal of the pagination component is executed immediately the component is loaded.
transform PaginationTransformer No undefined Provides functions for transforming custom data from the server to NgFlux Pagination object.
limitOptions number[] No [5, 10, 20, 30, 40, 50] Options for the dropdown menu of limits for the pagination component
limit number No 10 Default limit for the pagination component
