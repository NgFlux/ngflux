The NgFluxLoading service provides a global, configurable loading overlay for your application. It seamlessly manages blocking UI states during asynchronous operations, such as API requests, and can be configured to automatically trigger during Angular route transitions.

You can customize the loading behavior globally inside your NgFluxConfig object during the application bootstrap phase.
Property Type Required Default Description
showOnRouteNavigation boolean No false When true, automatically displays the overlay during Angular router navigation (NavigationStart to NavigationEnd/NavigationCancel/NavigationError).
component NgFluxComponent No NgFluxLoadingComponent (internal) A reference to a standalone component to render inside the overlay instead of the default spinner.

Inject the NgFluxLoading service into your components or services to control the overlay state manually during async processes.

When showOnRouteNavigation: true is enabled in your global configuration, you do not need to write any manual code in your components. The service automatically hooks into Angular's Router events to provide visual feedback during lazy-loading component chunks or resolving route data:

  • Triggers (start()): On NavigationStart.
  • Dismisses (stop()): On NavigationEnd, NavigationCancel, or NavigationError.
