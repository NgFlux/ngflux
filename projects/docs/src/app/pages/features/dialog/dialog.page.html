The NgFluxDialog service provides a modern, fully accessible alternative to native browser dialogs. It features asynchronous, non-blocking replacements for alert(), confirm(), and prompt(), while offering a robust mechanism to inject fully custom standalone components as dynamic dialog templates.

Display a simple warning or informational message to the user with an "OK" confirmation.

Ask the user a yes/no question. The method emits a boolean state indicating the user's choice.

Collect string inputs from the user inline. Emits the string value if confirmed, or null if the action is canceled.

For complex interfaces (like profile settings, payment gateways, or data filters), you can pass a custom Angular standalone component directly into the .open() configuration method.

Inject the special NGF_DIALOG_DATA token to receive incoming configurations, and use the NgFluxDialogRef handler to pass data back out when shutting the instance.
