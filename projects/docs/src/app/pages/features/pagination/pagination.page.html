The NgFluxPagination provides a robust, fully accessible pagination control interface. It handles server-side data tracking, custom payload transformation and reactive limit shifting via dropdown menus.

Below is a standard integration scenario showcasing data fetching tied directly to the pagination output stream.

You can define application-wide defaults for your pagination components inside your NgFluxConfig object during the application bootstrap phase.
Property Type Required Default Description
data input<any> Yes - The raw response payload received from your backend server.
preload input<boolean> No false When true, automatically fires the callback output signal immediately when the component initializes (mounted).
transform input<PaginationTransformer> No Config Default An object containing mapping methods to convert your unique backend JSON structure into a standard Pagination object.
limit input<number> No 10 The number of rows or items displayed per page.
limitOptions input<number[]> No [5, 10, 20, 30, 40, 50] An array of integers populated into a dropdown menu allowing users to change page limits dynamically.
Property Type Required Default Description
callback input<PaginationInfo> No - Output Signal. Emits the latest tracking criteria (page, limit) whenever a user navigates or adjusts row limits.
